# 🏠 Gestion des Courses - Farah Nour

Une application moderne et élégante pour gérer les achats de la maison en famille.

## ✨ Fonctionnalités
- 📊 **Tableau de bord** : Suivi du solde restant et des dépenses mensuelles.
- 🛒 **Liste de courses** : Ajoutez des articles avec photos, quantité et niveau d'urgence.
- 💰 **Gestion du Budget** : Ajoutez de l'argent ou fixez le solde restant précisément.
- 📈 **Statistiques** : Classement des produits les plus achetés et résumé des dépenses mois par mois.
- 👨‍👩‍👧‍👦 **Multi-utilisateurs** : Partagez le lien avec votre famille pour collaborer en temps réel.
- 📱 **Mobile Friendly** : Conçu pour fonctionner parfaitement sur smartphone.

## 🛠️ Installation & Hébergement (GitHub Pages)

### 1. Créer un dépôt sur GitHub
1. Connectez-vous à votre compte GitHub.
2. Cliquez sur **"New"** pour créer un nouveau dépôt (Repository).
3. Nommez-le (ex: `achats-maison`) et gardez-le en **Public**.

### 2. Téléverser les fichiers
1. Sur GitHub, cliquez sur **"uploading an existing file"**.
2. Glissez-déposez les fichiers suivants :
   - `achats.html` (Renommez-le en `index.html` pour que GitHub Pages le trouve automatiquement)
   - `fille.jpg` (La photo de Farah)
   - `README.md`
   - `.gitignore`

### 3. Activer l'hébergement (GitHub Pages)
1. Allez dans les **Settings** (Paramètres) de votre dépôt.
2. Cliquez sur l'onglet **Pages** dans le menu de gauche.
3. Sous **Branch**, sélectionnez `main` (ou `master`) et cliquez sur **Save**.
4. Votre lien sera disponible quelques minutes plus tard à l'adresse `https://votre-pseudo.github.io/achats-maison/`.

## 🔒 Configuration Firebase
L'application utilise **Firebase Firestore** pour synchroniser les données en ligne.
- La base de données est **déjà configurée** et active.
- Assurez-vous que vos règles Firestore autorisent l'écriture et la lecture.
